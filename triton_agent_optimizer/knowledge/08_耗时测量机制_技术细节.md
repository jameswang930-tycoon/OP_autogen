## 0. 核心原则

- **不改业务源码**：我们侧 = 在内存中改写 kernel_op.py 注入计时分支 → 生成临时文件运行；工业级 = 预定义的 torch forward + Event 包调用
- **计时器统一 = `torch.npu.Event(enable_timing=True)`**（设备侧时间戳, 无 profiler 扰动）
- **口径统一 = 流水化 ÷N**（verify ÷LOOP=30 / measure_final_event ÷10 / bench_all ÷10）
- **统计统一 = 多窗口 median**
- **破 L2 统一**（Ascend 无清 L2 API）：我们侧每窗口重建输入张量；工业级预分配 n_buf 组 buffer 轮换

## 1. 我们侧耗时测量（3 种场景）

### 场景 1: verify 段1 Event 快测（每轮决策主依据）

**流程**（verifier.py `_inject_event_timing` → `_event_e2e_ns`）：
1. 读 kernel_op.py 源码（字符串, **不碰源文件**）
2. 正则定位 `for \w+ in range(LOOP):` 标准循环（找不到 → 放弃, Event 测不出）
3. 提取循环体（缩进 > 循环的行）
4. 扫描循环前的 `\w+ = torch.randn?|rand|empty|zeros|ones(` 分配行（破 L2 重建对象）
5. 在循环前插入 Event 计时分支 → 生成 `round_dir/event_kernel.py`
6. 运行: `python3 event_kernel.py`（env: KERNEL_EVENT_TIME=1, KERNEL_LOOP=30, KERNEL_EVENT_REPS=5, KERNEL_EVENT_WARMUP=5）
7. 解析输出 `EVENT_E2E_US:x` → ×1000 → ns

**注入的计时器代码结构**：
```python
if os.environ.get('KERNEL_EVENT_TIME'):            # ← 注入分支
    for _ in range(5):                              # warmup (不计时)
        <循环体: 一次完整运算链的 kernel launch>
    torch.npu.synchronize()
    _ts = []; _keep = []
    for _r in range(5):                             # 5 个独立窗口
        x = torch.rand(...)                         # ★每窗口重建输入 (破 L2)
        _keep.append((x, ...))                      # ★防 caching allocator 复用地址
        _ev_s = torch.npu.Event(enable_timing=True)
        _ev_e = torch.npu.Event(enable_timing=True)
        _ev_s.record()                              # ← 计时器起点
        for _ in range(LOOP):                       # 窗口包 LOOP 次 → ÷LOOP
            <循环体>
        _ev_e.record()                              # ← 计时器终点
        _ts.append(_ev_s.elapsed_time(_ev_e))       # ms
    torch.npu.synchronize()
    _ts.sort()
    print('EVENT_E2E_US:%.2f' % (_ts[2] / LOOP * 1000.0))   # median ÷30, ms→us
    raise SystemExit(0)
```

**单位换算**：`elapsed_time()` 返回 **ms** → `median / LOOP * 1000` = 单次 **us** → `_event_e2e_ns` 再 ×1000 = **ns**（KEEP 判据 `e2e_event_ns`）

**窗口语义**：每窗口包 LOOP 次连续 launch ÷LOOP = 流水化口径（host 下发开销被隐藏, 近似纯设备时间）

### 场景 2: verify 段2 msprof 全量（过段1门才跑）

**无注入**，直接跑原文件：
```bash
# ① warmup 3 次裸跑 (预热 JIT/cache, 不计时)
python3 kernel_op.py            # env: KERNEL_LOOP=30
# ② msprof 包裹一次
msprof --output=<msprof_out> --application="python3 kernel_op.py" --ai-core=on   # env: KERNEL_LOOP=30
```
读 `op_summary*.csv`（★合并全部分片文件）：**目标 kernel（非 aclnn 前缀）Task Duration 求和 ÷ 30** = 单次耗时（profiler 采的设备时间）。

防护：H1 循环自校正（源码正则检测 KERNEL_LOOP 循环；丢失则 divisor=round(n_rows/num_launches)）；`n_rows < loop` → 告警"加速比存疑" + Event 不测（None → 方案A 不采纳）；msprof_0 目录每次 rmtree（防残留）。

### 场景 3: 最终测量（test/measure_final_event.py, 填表格用）

同注入思路，窗口语义可选：
- **默认流水化 ÷10**（`--pipelined 10`）：窗口内 `for _p in range(10): <循环体>` ÷10 —— 与工业级同口径
- 单次模式（`--pipelined 0`）：每窗口 1 次完整调用, host 开销全额计入
- 运行: `python3 test/measure_final_event.py` → 输出 `FINAL_EVENT_E2E_US` → **自动写回 bench_all.py 的 OUR_RESULTS_US**（`("op":)None → ("op":)值`）
- 单位：打印值 = median/`_PIPE`×1000（elapsed_time 是 ms, 已换算 us）

## 2. 工业级测量（eager / compile / fa）—— 完全不改代码

### 被测对象 = bench_industrial.py 里预定义的 forward（每算子一个 torch 表达式）

| 算子 | forward（eager/compile 都跑它） |
|---|---|
| matmul | `torch.matmul(F.gelu(x@w1+b1, approximate="tanh"), w2)`（两层 MLP 链） |
| attention_mlp | 自注意力 + MLP 链（QKV→S→softmax→O→GELU→FC2→+残差） |
| matmul_relu | `F.relu(x @ w)` |
| matmul_transpose | `a @ b.t()` |
| rms_norm | `x / torch.sqrt((x*x).mean(-1,keepdim=True)+eps) * w` |
| rms_norm_residual | `(x+res) / sqrt(mean+eps) * w` |
| layernorm | `F.layer_norm(x, [N], w, b, 1e-6)` |
| sigmoid / softmax / vector_add / fused_add_mul | 对应 torch 逐元素算子 |
| flash_attention | `torch_npu.npu_prompt_flash_attention(q,k,v, num_heads, scale, input_layout="BNSD")`（fa 模式, fp16） |
| conv2d | `F.conv2d(x, w, stride=1, padding=P)` |
| conv_bias_relu | `F.relu(F.conv2d(x, w, b, stride=1, padding=P))` |
| batchnorm2d | `F.batch_norm(x, rm, rv, g, b, training=False, eps=eps)` |
| maxpool2d | `F.max_pool2d(x, (KH,KW), stride=(SH,SW), padding=PAD)` |
| conv1d | `F.conv1d(x, w, b)` |

### eager vs compile 的区别（只在这行代码）

```python
# eager: 直接调用 → torch 逐 op 下发 → 每 op 一个 aclnn kernel
fn(*bufs[i])

# compile: 先编译成 GE 图再调用 → 图融合 → CANN 融合 kernel
cfg.mode = "max-autotune"
backend = torchair.get_npu_backend(compiler_config=cfg)
fn = torch.compile(forward, backend=backend)      # torchair 不可用 → 回退 eager (actual_mode 标记)
fn(*bufs[i])
```

### 计时（bench_common.measure_event, do_bench 同款）

```python
# ① 估时长: fn(0) 5 次 → est_ms
# ② 预算折算: n_warmup = warmup_ms(25)/est, n_rep = clamp(rep_ms(100)/est, 5, 50)
# ③ warmup: n_warmup 次 fn(0) (不计时)
# ④ 测量:
for i in range(n_rep):
    s.record()
    for _ in range(10):                    # ★流水化 ÷10 (--pipelined 默认 10)
        fn(*bufs[i % 32])                  # ★轮换 32 组输入 buffer 破 L2 (预分配, 无注入)
    e.record()
    times.append(s.elapsed_time(e) / 10)
median → time_us (×1000, ms→us)
```

### 运行命令

```bash
python3 bench_industrial.py matmul --mode eager          # 单算子单模式
python3 bench_industrial.py matmul --mode compile
python3 bench_industrial.py matmul --mode eager --pipelined 10   # 显式流水化
python3 bench_all.py                                       # 全部 17 算子 × eager+compile (+fa) 自动跑
python3 bench_all.py --op conv2d                           # 只跑一个算子
```

产物: `outputs/industrial_<op>_<mode>_tflops.json`（time_us=median / actual_mode / method / pipelined_n / note 口径声明）

## 3. 两侧对照总结

| | 我们侧 | 工业级 |
|---|---|---|
| 被测对象 | input/<op>/kernel_op.py（自写 triton） | bench_industrial.py 预定义 torch forward |
| 计时器 | `torch.npu.Event` **注入**进 main()（临时副本） | `torch.npu.Event` 包 forward（无注入） |
| 破 L2 | 每窗口**重建输入张量**（正则抓分配行 + `_keep` 防 GC） | **预分配 n_buf=32 组 buffer 轮换** |
| 口径 | verify ÷LOOP=30 / 最终测量 ÷10（流水化） | ÷10（流水化, 默认） |
| 统计 | 5 窗口 median | n_rep(5~50) median |
| warmup | 5 次循环 | 25ms 预算自适应 |
| 改代码 | 注入临时副本, 源文件不碰 | 完全不用改 |
| 单位 | elapsed_time 是 ms → 全部 ×1000 转 us（★已修 1000× bug） | 同上 |

## 4. 关键坑（测量相关）

1. `elapsed_time()` 返回 **ms**——所有打印前必须 ×1000（measure_final_event 曾漏, 差 1000 倍, 已修）
2. 破 L2 重建的 `_keep` 必须持有张量——否则 caching allocator 复用地址, 破 L2 失效（实测虚高比值全 ≈1.0）
3. msprof op_summary 可能按 `{device}_{model}_{iter}` 拆多文件——必须合并, 只读第一个会漏 kernel
4. verify 的 Event 只在 `n_rows >= loop` 时才算数（循环完整=Event 真实）；Event 缺失 → 方案A 不采纳（防 msprof 欠采假 200x 毒 best）
5. 工业级 compile 依赖 torchair——缺装自动回退 eager 并标 `actual_mode="compile→eager"`, 回退值不参与最优
6. 我们侧注入的派生张量（conv2d 的 F.unfold 结果）不在重建范围——工作集小, 影响有限（已知声明）
